Visual system

Themes, prompt, wallpapers, and fetch output

The repo mostly uses Rose Pine and Catppuccin-adjacent styling, with Stylix handling global integration and individual programs opting out when they need custom settings.

Stylix

modules/config/stylix.nix

System-level Stylix, Rose Pine base16 scheme, wallpaper fallback, DejaVu fonts, JetBrains Mono Nerd Font, and Qt target disabled on Linux.

modules/home/stylix.nix

Linux user-level Stylix, Rose Pine scheme, wallpaper fallback, Papirus icons, Bibata cursor, and font definitions.

Program opt-outs

Several modules disable Stylix targets so their local theme config wins: Ghostty, Alacritty, Helix, Btop, Waybar, Hyprland, Mako, tofi, Nixcord/Vencord, Spotify, and Zen Browser.

Starship prompt

modules/home/starship.nix defines a custom my.starship option set. Formats include default, minimal, format1, format2, and filled. Themes include tokyo_night, catppuccin, and gruvbox. The active setting in shells.nix is format2 with catppuccin.

Fastfetch

modules/home/fastfetch/default.nix uses a local image logo and renders grouped system, hardware, package, SCM, network, and Spotify information. Darwin uses AppleScript for Spotify; Linux uses playerctl.
