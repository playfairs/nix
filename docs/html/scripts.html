Wrapped commands

Scripts included in Home Manager

modules/home/packages.nix reads every regular file in scripts/ and wraps it with pkgs.writeShellScriptBin, so these become commands in the user environment.

Script catalog

Command Purpose
1000-7 Interactive subtraction drill that restarts on wrong answers.
animal Fetches a random cat, dog, fox, or duck image URL and copies it when possible.
badapple Runs Bad Apple through mpv with caca terminal video output.
calc Evaluates a math expression through bc -l.
ds Shows drive usage in bytes, GB, and TB with color thresholds.
extract Archive extractor for tar, gz, bz2, rar, zip, 7z, and related formats.
findbig Lists the 20 largest paths under the current directory.
fm Last.fm helper for auth, now-playing display, and loving the current track.
gitignore Adds a path or wildcard basename to the repository .gitignore.
invis Uses fzf to choose an invisible Unicode character and copy it.
math Interactive timed arithmetic practice with stats.
push Commits and pushes file-by-file changes for ~/.nix and ~/.config.
remux Remuxes media to MP4 with ffmpeg stream copy.
snowflake Generates a Snowflake-style numeric ID with a sequence file in /tmp.
systemfetch Small shell system summary for host, OS, kernel, shell, terminal, and working directory.
trim-generations Interactive Nix generation cleanup helper with keep-by-generation and keep-by-days logic.
uuid Generates random lowercase hex from /dev/urandom; default length is 32.
word Chooses a random dictionary word of a requested length.

Dependencies to remember

Some scripts expect external commands at runtime: curl, jq, fzf, clipboard tools, mpv, ffmpeg, bc, df, du, sort, head, and archive tools. Many are already installed by packages.nix, but API-based scripts still need network access and credentials.
