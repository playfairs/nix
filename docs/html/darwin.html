Darwin path

nix-darwin and macOS user config

Darwin hosts receive system modules from modules/config and user modules from modules/home. The macOS-specific Home Manager module imports wallpaper and Dock support.

macOS defaults

modules/home/darwin.nix declares Finder, Dock, screencapture, clock, desktop services, global keyboard/repeat, metric units, window dragging, Stage Manager behavior, and cloud-save preferences.

Finder

Shows extensions and hidden files, path bar, folder-first sorting, no desktop icons, no extension warning, trash cleanup.

Dock

Autohide, orientation, size, no recents, app minimize behavior, and host-provided entries.

Screenshots

PNG screenshots to Pictures, clipboard target, no shadow.

Keyboard

Function keys, repeat speed, optional command/alt/control/fn normalization and Caps to Escape.

Dock module

modules/dock/default.nix creates targets.darwin.dock. It compares current Dock URIs to desired entries, removes stale entries, adds desired app bundles, and restarts Dock only when the list changes.

modules/dock/packages.nix builds a tiny Rust helper that detects OS version so the default App Drawer path can adapt for newer macOS versions.

Wallpaper module

modules/wallpaper.nix adds programs.setWallpaper. When enabled, Home Manager activation resolves the configured image path and tells Finder to set the desktop picture.

Window manager hooks

modules/aerospace.nix defines a custom nix-darwin service option named services.airspace that can launch AeroSpace with an optional TOML config. modules/config/yabai.nix contains disabled Yabai settings and enabled skhd bindings for Ghostty and fullscreen toggling.
