User layer

Home Manager modules

modules/home configures user packages, shells, terminals, desktop app settings, editors, media tools, and platform-specific user activation.

Base home state

home-manager.nix

Sets username, platform home directory, state version 24.11, and EDITOR=hx.

default.nix

Imports all Home Manager modules recursively and applies overlays/unfree predicate.

packages.nix

Wraps every file in scripts/ as a shell command and installs the main app/tool package set.

xdg.nix

Sets Linux browser defaults to Zen and provides a Ghostty desktop entry.

Shell workflow

shells.nix enables zsh, nushell, fzf, carapace, eza, zoxide, and imports Starship and Elvish. It sets NH_FLAKE=$HOME/.nix and adds Nix/Home Manager profile paths to the session.

Editors and terminals

File Purpose
helix.nix Default editor with Nix/Rust/Zig/TypeScript/Go language servers, Discord RPC LSP, custom statusline, diagnostics, and keybindings.
ghostty.nix Ghostty on Linux and Ghostty binary on Darwin, Rose Pine theme, opacity, hidden macOS titlebar, platform font sizing.
alacritty.nix Darwin-only Alacritty with Rose Pine, buttonless window, opacity, JetBrains Mono Nerd Font, and font-size bindings.
foot.nix Linux Foot terminal with JetBrains Mono Nerd Font and alpha override.
yazi.nix Yazi file manager with Rose Pine Moon flavor, natural sort, hidden files visible, and image preview settings.

SCM and cleanup

scm.nix configures Git from either the old development.git shape or the newer development.scm.git shape, optionally enables Mercurial, and installs lazygit, glab, and gh. nh.nix enables automatic cleanup with --keep-since 4d --keep 3.
