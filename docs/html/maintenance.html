Care and feeding

Maintenance, formatting, and automation

These are the repo-level tools and conventions that keep the configuration usable after the initial setup.

Formatting

The formatter wrapper is built with treefmt-nix. It enables nixfmt, nixf-diagnose, rustfmt, toml-sort, shellcheck, shfmt, and swift-format. 

nix fmt

Cleanup

modules/home/nh.nix enables nh clean with --keep-since 4d --keep 3. The separate trim-generations script offers an interactive cleanup path for user, Home Manager, channels, and system profiles.

Automation project

configs/auto is a Rust workspace with a Swift bootstrapper. The bootstrap-darwin target installs Nix when missing, handles macOS plist patching for newer versions, applies nix-darwin, and applies Home Manager unless skipped. The test target prints OS and Nix detection state. 

cd ~/.nix/configs/auto
cargo run --bin test
cargo run --bin bootstrap-darwin -- -f macbook

Adding a new host

1Create configs/hosts/name.nix.
2Use -x86 or -aarch64 suffix for Linux, or no suffix for Darwin.
3For Linux, set system.hardware-module to a file in configs/hosts/hardware.
4Run nix flake show or the relevant switch command to verify the new output appears.
