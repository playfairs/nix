Linux desktop layer

Window managers, panels, launchers, and notifications

The repo supports multiple Linux desktop paths. Host files choose what is active; Home Manager modules declare the user-level configuration.

Hyprland

modules/home/hyprland.nix reads desktop.hyprland from the host. It maps monitor objects into Hyprland monitor strings, starts swww-daemon, Waybar, and Mako, sets wallpaper, and defines workspaces, media keys, screenshots, PiP rules, opacity, blur, gaps, and bindings.

Niri

modules/home/niri/default.nix writes .config/niri/config.kdl on Linux. The KDL config starts Xwayland satellite, Waybar, Mako, and swww, sets Wayland environment variables, configures keyboard/touchpad, focus ring, shadows, animations, PiP rules, and extensive workspace/window bindings.

MangoWC

modules/mangowc.nix is a custom Home Manager module that serializes MangoWC settings to mango/config.conf and can generate startup.sh. modules/home/mango.nix supplies the actual MangoWC settings and only enables them when desktop.mangowc.enable is true.

Plasma

modules/home/plasma.nix uses plasma-manager. It enables Plasma when requested, adds panel/colorizer/tiling packages, configures a top autohide panel, KWin shortcuts, nine desktops, KRunner position, and Picture-in-Picture window rules.

Panel, launcher, notifications

waybar/

Writes Waybar JSON and CSS with launcher, workspace/window, network, audio, battery, tray, and clock modules.

tofi.nix

Configures a full-screen tofi launcher with Rose Pine colors and large JetBrains Mono text.

mako.nix

Configures Linux notifications with Rose Pine colors, top-center anchor, icons, borders, and timeouts.

xdg.nix

Sets Linux defaults for browser URL schemes and Ghostty desktop entry.
