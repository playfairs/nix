Short version

What Nix is doing in this repo

Nix makes system state declarative. Instead of installing things one by one and hoping the machine stays understandable, this repo describes what each machine should look like and lets Nix build that state.

The pieces

Nix

The package manager and build language. It evaluates this flake and realizes packages, modules, and generated files.

NixOS

The Linux OS module system used by laptop-x86, vm-x86, and vm-aarch64.

nix-darwin

The macOS system layer used by macbook, macmini, and mac-vm.

Home Manager

The user layer used everywhere for shells, terminals, editors, app settings, scripts, and dotfiles.

Why flakes matter here

The lock file pins dependencies, and flake.nix exposes named outputs. That is why commands can target .#macmini or .#laptop-x86 instead of relying on hidden local state.

How to think about changes

Change host identity in configs/hosts. Change OS behavior in modules/config. Change user programs in modules/home. Change builder behavior in utils/default.nix. Change scripts in scripts/.
