Host configuration reference

Each host file is data, not a module. The values are consumed by shared modules through flakeConfig.

Host attrset schema

user

username, displayName, and initial password seed for user creation.

system

Host name, timezone, keyboard, Dock, graphics, networking, greeter, services, boot, and hardware module path.

desktop

Enables Plasma, Hyprland, Niri, or MangoWC and may carry monitor definitions.

development

Git and Mercurial identity, default branch, and Forge types used by SCM and Fastfetch.

Hardware files

configs/hosts/hardware contains generated NixOS hardware modules. They define filesystems, swap, kernel modules, CPU microcode, and host platform. Linux host profiles point at these with system.hardware-module.
