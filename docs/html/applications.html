Daily tools

Application and program configuration

The Home Manager layer configures core programs directly and installs a broad package set through modules/home/packages.nix.

Program modules

Module Configuration
asteride.nix Imports AsterIDE Home Manager module, enables AsterIDE, sets scale and cherry blossom dark theme.
btop.nix TTY theme, vim keys, one-second updates, Celsius temps, truecolor.
fastfetch/default.nix Custom logo, system/hardware/package/network/SCM/Spotify sections, Darwin-specific Spotify AppleScript support.
nixcord/default.nix Nixcord disabled but Discord/Vesktop package selection and plugin config are declared; Vesktop is selected on aarch64 Linux.
obs.nix Enables OBS Studio on Linux.
spotify.nix Spicetify and spotify-player are currently disabled, but Rose Pine player theme and Beautiful Lyrics extension are prepared.
zen.nix Zen Browser Home Manager target is disabled, while packages/default apps still reference Zen in Linux defaults.

Package groups

Development

nix-dev, nil, nixd, Java language server, Node.js, pnpm, uv, F#, Mercurial, gh, glab, lazygit.

Media

Spotify, ffmpeg, OBS, IINA on Darwin, VLC on Linux, Flameshot, Shottr, player tools.

Desktop apps

Discord variants, Telegram, WhatsApp Electron, Prism Launcher, LibreOffice, KDE Connect, UTM, Zed, Gram.

CLI utilities

fd, ripgrep, tree, wget, unzip, rar, gum, pv, file, inetutils, uutils, ddgr, onefetch.

Fun and misc

nyancat, stockfish, pokemon colorscripts, mednafen, urban-cli, animal/media helpers from scripts.

Platform extras

Linux adds Wayland tools and communication apps; Darwin adds app wrappers, Rustup, bindfs, aria2, duti, and macOS utilities.
