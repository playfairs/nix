Quick reference

A compact index of where the important things live.

Key files

Path Role
flake.nix Top-level flake inputs, host mapping, and repo outputs.
configs/ Host profiles, platform detection, and macOS bootstrap automation.
configs/hosts/ Host-specific settings and hardware module references.
configs/hosts/hardware/ Generated Linux hardware modules used by NixOS hosts.
modules/config/ System-level modules imported by NixOS and nix-darwin.
modules/home/ User-level Home Manager modules and app defaults.
modules/home/default.nix Main Home Manager module loader and common config entrypoint.
modules/home/packages.nix User package selections and wrapped repository scripts.
modules/home/shells.nix Shell and terminal configuration plus prompt and session setup.
modules/home/home-manager.nix Base Home Manager configuration and platform defaults.
modules/home/starship.nix Starship prompt themes and format settings.
modules/home/helix.nix Editor configuration and language server support.
modules/home/ghostty.nix Terminal application settings and platform integration.
modules/home/darwin.nix macOS-specific Home Manager options and services.
modules/config/default.nix System module loader and common system arguments.
modules/config/scm.nix Version control tool configuration and repository helpers.
scripts/ Shell scripts exposed into user environments.
utils/ Helper functions, builders, and reusable repo utilities.

Common edits

Change user identity

Edit configs/hosts/<host>.nix under user and development.scm.

Change display manager

Edit system.greeter in the host file.

Add a package

Edit modules/home/packages.nix for user packages or modules/config/packages.nix for system packages.

Add a script

Add an executable-style shell file to scripts/; Home Manager wraps regular files automatically.

Change theme

Edit modules/config/stylix.nix, modules/home/stylix.nix, or per-app opt-out modules.

Change desktop behavior

Edit modules/home/hyprland.nix, niri/, mango.nix, or plasma.nix.
