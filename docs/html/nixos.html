OS layer

NixOS and shared system modules

modules/config is imported for both NixOS and nix-darwin. Most modules use lib.optionalAttrs linux or platform checks to apply only where they make sense.

Core modules

File What it configures
default.nix Imports all config modules, imports the host hardware module on Linux, sets overlays, unfree predicate, and state version.
nix.nix Nix flakes, pipe operators, build parallelism, and Cachix substituters for nix-community and oxalica.
boot.nix Latest Linux kernel, v4l2loopback for OBS virtual camera, systemd-boot, EFI mount, kernel params, module blacklists, and swappiness.
hardware.nix Graphics, 32-bit graphics on x86_64, AMD OpenCL if requested, NVIDIA settings, PRIME options, and Bluetooth.
users.nix Creates the host user with zsh, wheel/libvirtd/audio groups on Linux, and UID/home/knownUsers on Darwin.
keyboard.nix Linux XKB layout plus Workman variant; macOS key normalization and Caps Lock to Escape.
i18n.nix Timezone from host config and Australian/US locale support.

Desktop and services

File Behavior
display-manager.nix Chooses GDM, Ly, or SDDM from system.greeter; enables Niri and Hyprland programs from desktop; turns on XDG portal.
services.nix Tailscale, Flatpak, Blueman, QEMU guest tools, Spice agent, Plasma 6, fwupd, PipeWire with JACK/Pulse/ALSA, libinput, OpenSSH, and Samba.
networking.nix Host name, NetworkManager, firewall, DHCP, per-interface DHCP, and bridge definitions.
packages.nix System shells and packages, KDE package exclusions, nix-ld, Steam, virt-manager, dconf, Thunar, zsh.
virtualisation.nix libvirtd, Spice USB redirection, and a large VM variant profile.
security.nix Linux doas, sudo-rs reboot rule, polkit; macOS Touch ID for sudo.

Host-facing knobs

system.graphics.wanted

Feeds X server video drivers and AMD OpenCL detection.

system.graphics.blacklists

Feeds boot.blacklistedKernelModules.

system.networking

Controls NetworkManager, firewall, DHCP, and interfaces.

system.greeter

Switches display manager between gdm, ly, and sddm.
