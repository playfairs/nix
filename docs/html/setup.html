Getting running

Clone, configure hosts, and switch your flake

This repository is designed to live at ~/.nix. The top-level flake.nix imports host profiles from configs/hosts and outputs Home Manager plus NixOS or nix-darwin configurations based on each host name.

Clone the repo

Clone the repo into ~/.nix so the built-in flake path matches the docs and tooling. 

git clone https://github.com/playfairs/nix ~/.nix
cd ~/.nix

If you already cloned elsewhere, use that path in the flake commands instead of ~/.nix.

Enter the dev shell

The repository includes utils/dev/devsh.nix for a reproducible development shell with Rust, Nix, formatting tools, and helper scripts. 

nix develop

Format repository nix files with the bundled formatter:

nix fmt

Edit host profiles

Host names live in configs/hosts/*.nix. Open the host file for the machine you want to customize and update settings like system.hostname, timezone, networking, greeter, desktop, and user.

Linux hosts also set a hardware module path, for example:

system.hardware-module = ./hardware/laptop-x86.nix;

The supported hosts in this repo include:

macbookmacminimac-vmlaptop-x86vm-x86vm-aarch64

Generate Linux hardware modules

Linux host hardware modules are stored under configs/hosts/hardware. For a new Linux machine, run nixos-generate-config on the target system, then copy or adapt the generated file into that folder and point the host config at it. 

# boot into the target Linux machine or chroot
sudo nixos-generate-config --root /mnt
# copy the generated hardware module into the repo
cp /mnt/etc/nixos/hardware-configuration.nix ~/.nix/configs/hosts/hardware/new-host.nix

Then set the host file to use it:

system.hardware-module = ./hardware/new-host.nix;

Switch Home Manager

This repo includes Home Manager support for all hosts. Use the built-in nh helper or the flake command directly. 

nh home switch -c macmini
nh home switch -c macbook
nh home switch -c laptop-x86

Or run Home Manager directly from the flake:

home-manager switch --flake ~/.nix#macmini

Switch NixOS

Linux hosts with x86 or aarch64 suffixes also build NixOS outputs. 

sudo nixos-rebuild switch --flake ~/.nix#laptop-x86
sudo nixos-rebuild switch --flake ~/.nix#vm-x86
sudo nixos-rebuild switch --flake ~/.nix#vm-aarch64

Switch nix-darwin

macOS hosts use darwinConfigurations from the same flake. 

sudo darwin-rebuild switch --flake ~/.nix#macmini
sudo darwin-rebuild switch --flake ~/.nix#macbook
sudo darwin-rebuild switch --flake ~/.nix#mac-vm

macOS bootstrap helper

The repo includes a bootstrap helper in configs/auto for installing Nix and nix-darwin, then applying the host configuration. 

cd ~/.nix/configs/auto
swift ./bootstrap.swift
cargo run --bin bootstrap-darwin -- -f macbook
Note: the bootstrapper writes system files and invokes sudo. Read configs/auto/README.adoc before running it on a fresh machine.
