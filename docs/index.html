Repository overview

My Nix Flake with docs for all hosts and platforms.

This site explains how the repository is organized, how host profiles are structured, and how the shared flake produces Home Manager, NixOS, and nix-darwin configurations from the same source tree.

The documentation is a map for the repo; it covers host layout, platform specific outputs, and the commands used to build and switch each machine from a single configuration source.

Look at setup, architecture, host profiles, or reference pages to see how the repo keeps everything modular, reusable, and easy to maintain. Or don't, I don't care.
